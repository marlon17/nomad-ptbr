# Sobre o Project NOMAD

O Project NOMAD ("NOMAD", para abreviar) é um projeto iniciado em 2025 por Chris Sherwood, da [Crosstalk Solutions, LLC](https://crosstalksolutions.com). O objetivo do projeto não é criar apenas mais um utilitário para armazenar recursos offline, mas sim permitir que os usuários rodem o seu próprio "computador de sobrevivência" definitivo. O nome começou como um retroacrônimo, Node for Offline Maps, Archives, and Data (Nó para Mapas, Arquivos e Dados Offline), mas hoje em dia nós o chamamos apenas de NOMAD.

Enquanto muitos computadores de sobrevivência offline semelhantes são projetados para rodar em hardware mínimo e leve, o Project NOMAD é exatamente o oposto. Para instalar e rodar as ferramentas de IA disponíveis, recomendamos fortemente o uso de um dispositivo robusto, com GPU, para aproveitar ao máximo a sua instalação. Veja o [Guia de Hardware](https://www.projectnomad.us/hardware) para recomendações detalhadas de montagem em três faixas de preço.

Desde o seu lançamento inicial, o NOMAD cresceu e passou a incluir um chat de IA integrado com uma Base de Conhecimento para respostas baseadas em documentos, um Teste de Desempenho com ranking da comunidade, coleções de conteúdo curadas com opções em níveis e um assistente de Configuração Fácil para que novos usuários comecem a usar rapidamente.

O Project NOMAD é de código aberto, lançado sob a [Licença Apache 2.0](https://github.com/Crosstalk-Solutions/project-nomad/blob/main/LICENSE).
